# LinguaPlay

O **LinguaPlay** é um mini-game web para praticar vocabulário italiano com traduções para o português brasileiro. O objetivo é tornar o aprendizado de novos termos mais interativo por meio de perguntas e respostas.

## Funcionalidades

- Seleção de temas de vocabulário.
- Tradução de palavras do italiano para o português.
- Validação de respostas com suporte a alternativas de tradução.
- Feedback visual para acertos e erros.
- Opção para pular palavras ou encerrar a partida.
- Barra de progresso durante o jogo.
- Placar com acertos, erros e aproveitamento.
- Resumo dos resultados ao final da partida.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Clone este repositório ou baixe os arquivos do projeto.
2. Abra o arquivo `index.html` em um navegador.
3. Escolha um tema e comece a jogar.

Não é necessária a instalação de dependências.

## Objetivo do projeto

Projeto desenvolvido para praticar desenvolvimento web com tecnologias fundamentais, trabalhando com manipulação do DOM, eventos, lógica de jogo e organização de arquivos.

---

Desenvolvido como projeto de aprendizado auxiliar ao que faço no Duolingo.
